# Mezang Traditional Restaurant — Website

A single-page website for Mezang Traditional Restaurant (Chandmari, Agartala).

## Files
- `index.html` — the whole site (HTML, CSS, and content in one file, no build step needed)

## How to test it on GitHub Pages

1. Create a new repository on GitHub (e.g. `mezang-website`).
2. Upload `index.html` to the root of the repo (drag-and-drop works, or use "Add file → Upload files").
3. Commit the file to the `main` branch.
4. Go to **Settings → Pages** in the repo.
5. Under "Build and deployment", set **Source** to `Deploy from a branch`.
6. Set **Branch** to `main` and folder to `/ (root)`, then **Save**.
7. Wait 1–2 minutes, then refresh the Pages settings tab — GitHub will show your live URL, something like:
   `https://<your-username>.github.io/mezang-website/`

That's it — no build tools, no dependencies, it's plain HTML/CSS.

## Editing later
Everything (styles, text, links) lives inside `index.html`. Open it in any text editor or back in Claude to make changes, then re-upload/commit the updated file.
